Definitions & Classification Guide

Use the primary purpose of the discussion—not a single keyword—to select the best category.

Important Type of Board Work rule: Classify each phase of an agenda item separately. A presentation may be Receiving Information, followed by Asking Questions or discussion, with only the actual motion/vote period classified as Decision / Action.
